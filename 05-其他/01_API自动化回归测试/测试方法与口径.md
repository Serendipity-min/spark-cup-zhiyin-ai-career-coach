## 一、测试原则与核心目标

1. **零修改线上 Workflow**：严格在星辰线上既有发布的工作流（Flow ID: `7484109920560275456`）上进行纯客户端 API 自动化测试，不修改任何线上 Prompt、节点参数或连线。
2. **端到端真机联调**：通过讯飞星辰 OpenAPI (`/workflow/v1/chat/completions` 与 `/workflow/v1/resume`) 真实 HTTP/SSE 协议驱动，完全脱离本地假 Mock。
3. **确定性与断言隔离**：断言引擎完全独立于对话转录过程，严格针对工作流最终 Stop 产生的六大章节 Markdown 报告正文执行质量判定。

## 三、断言判定口径与硬门禁

1. **章节完整性**：必须 100% 覆盖六大核心章节（`岗位核心能力拆解`、`能力现状评估`、`关键差距分析`、`4周行动计划`、`面试准备建议`、`整体评分`）。任一缺失直接判定 **FAIL**。
2. **模板变量泄漏**：全文检索正则表达式 `\{\{[^}]+\}\}`，凡存在未替换模板占位符直接判定 **FAIL**。
3. **岗位保真度**：最终报告正文必须精确包含目标岗位核心名称，禁止大模型自作主张修改岗位或串联其他岗位。
4. **中断轮次硬门禁**：实际中断轮次必须严格等于预期中断轮次（如 T02 必须为 2 轮，T08 必须为 4 轮）。
5. **Abort 与状态机同会话重入**：
   - 捕获讯飞原生 Abort 指令响应：`code=23802`，`message="Question-answer node data retrieval timeout(Received abort instruction)"`。
   - 同会话发起新岗位后，生成的新岗位报告中算法残留率为 **0.0%**。

## 四、核心统计指标口径

- **P50 耗时**：所有案例端到端总耗时的中位数（**100.27 秒**）。
- **P95 耗时**：所有案例端到端总耗时的 95 分位数（**115.89 秒**）。
- **平均最终生成耗时 (`final_generation_ms`)**：记录最后一次用户 Resume 发出到最终收到 Stop 事件的大模型长文本生成耗时（平均 **91.83 秒**）。
