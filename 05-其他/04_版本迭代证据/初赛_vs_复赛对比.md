# 职引 · AI职业诊断官 —— 初赛 vs 复赛架构与能力对比

## 一、全景演进对比矩阵

| 对比维度 | 初赛版本 (v1.0 原型) | 复赛版本 (v5.3.x 最终交付版) | 演进价值与解决痛点 |
| :--- | :--- | :--- | :--- |
| **工作流节点与拓扑** | 6 个节点（简单单链线性结构） | **22 个节点、28 条连线**（高内聚状态机） | 解决流程死板、无状态流转与断点恢复能力问题 |
| **交互收集模式** | 单轮输入（要求用户一次性粘贴全量信息） | **3 轮渐进式核心问答中断**（Q1 岗位 → Q2 学历 → Q3 实践） | 大幅降低学生使用门槛，画像采集完整度提升 100% |
| **意图与状态控制** | 无输入意图分类，不支持重新开始 | **前置意图预识别 + 8 大会话变量状态机** | 支持“中途换岗位”、“重新开始”与“断点自动恢复” |
| **证据支持体系** | 仅依赖大模型通用内建常识，容易产生幻觉 | **动态联网 JD 搜索 + 10 篇专业 RAG 知识库融合** | 严格遵循“用户自述 > 实时 JD > 知识库”事实边界 |
| **诊断报告输出** | 泛化文本建议，无固定格式 | **标准化六大核心章节 + 6 维度量化评分 (S/A/B/C)** | 输出清晰 4 周冲刺周度交付物与面试准备建议 |
| **质量安全门禁** | 无自动化校验 | **Python 代码节点实时执行 6 大章节与变量合规检查** | 杜绝模板变量 `{{...}}` 残留，保障报告可信度 |
| **自动化测试保障** | 零自动化测试，纯手工点选调试 | **42 用例全量 API 自动化回归套件 (100% 通过)** | 工业级接口回归，覆盖稳定性、异常中断与重置 |

---

## 二、关键技术升级亮点

1. **状态机与会话重置能力突破**：
   - 初赛版本如果用户中途想换方向，必须手动刷新整个网页重新开始，无法保留历史记忆；
   - 复赛版本构建了具备 8 大环境变量的双重分支器（Branch 1 判定输入意图，Branch 2 判定字段断点），实测支持在同一会话中无缝执行 `STATE_RESET` 与 `ABORT_AND_SWITCH`。
2. **多源证据融合机制**：
   - 彻底破除传统 Agent“纸上谈兵”的虚构弊端，工作流节点 16 实时检索公开企业校招 JD，节点 17 检索专业学习路线与高频真题，将证据严格打上来源标签（公开 JD / 知识库 / 通用常识）。
3. **确定性自动化质量门禁**：
   - 引入独立的 `ifly-code` Python 校验节点，实时对大模型生成的文本进行结构化正向扫描与清洗，保障每次生成的 Markdown 均符合六大章节标准。
