# 校招学习路线库 · 2026 版

> 8 大岗位方向 × 4 周冲刺 × 6 个月长线准备
> 包含：每日时间分配 / 推荐资源 / 阶段产出 / 衡量标准

---

## 一、产品经理（PM）

### 4 周冲刺路线（无经验 → 1 段"包装实习"）

**Week 1：JD 通读 + 简历打底**
- 每日 2h：通读 10 个 PM JD，提炼高频关键词
- 每日 1h：用墨刀/Figma 仿造 1 个产品的 PRD
- 产出：1 份 PM 定制简历 + 1 份 PRD 作品

**Week 2：项目深度复盘**
- 选 1 个校园/实习项目，按 STAR 法则写 1000 字深度复盘
- 学 SQL 基础（窗口函数、JOIN）
- 产出：项目复盘文档 + SQL 50 题刷题笔记

**Week 3：产品思维训练**
- 每日 1 个 Case Study：分析 1 个产品的功能设计逻辑
- 写 3 篇产品分析文章（每篇 800 字）
- 产出：产品分析作品集

**Week 4：模拟面试**
- 找 3 位学长/朋友 mock interview
- 准备 30 个高频产品面试题答案
- 产出：面试录音 + 复盘笔记

**6 个月长线路线（0 → 大厂 offer）**
- 月 1-2：基础 + 1 段大厂实习
- 月 3-4：进阶 + 项目深度
- 月 5-6：笔面试冲刺

### 每日时间分配（PM 6 个月长线版）

| 时段 | 内容 | 时长 |
|------|------|------|
| 工作日 7:00-9:00 | 阅读产品公众号 / 看产品发布会 | 2h |
| 工作日 19:00-21:00 | 项目实践 / 课程学习 | 2h |
| 周末 | 完整项目开发 / 行业研究 | 8h/天 |

### 推荐资源

- **公众号**：俞军产品方法论、产品犬舍、三节课、人人都是产品经理
- **网站**：即刻、知乎产品话题、36 氪
- **书籍**：《俞军产品方法论》、《人人都是产品经理》、《启示录：打造用户喜爱的产品》
- **课程**：起点学院产品经理培训、B 站产品经理免费课
- **社区**：人人都是产品经理社区、即刻产品话题

### 阶段产出衡量

| 阶段 | 产出物 | 合格标准 |
|------|--------|---------|
| 1 个月 | 1 份 PRD + 10 个 JD 分析 | PRD 能让研发看懂 |
| 3 个月 | 1 个 side project + 1 段实习 | 项目可演示 |
| 6 个月 | 3 段实习 + 1 份深度作品集 | 可面试 BAT |

## 二、数据分析师（DA）

### 4 周冲刺路线

**Week 1：SQL + Excel 基础**
- SQL 50 题（中等级）
- Excel 数据透视表 / VLOOKUP / 图表
- 产出：50 题 SQL 笔记 + 1 个 Excel 仪表盘

**Week 2：Python + 统计学**
- Pandas 基础（groupby、merge、pivot_table）
- 描述统计 + 假设检验
- 产出：Python 数据分析 demo

**Week 3：业务案例 + 报告**
- 模仿 3 个真实业务分析报告
- 学 Tableau / Power BI
- 产出：1 份业务分析报告（带图表）

**Week 4：业务 sense + 面试**
- 50 道业务面试题（如"DAU 下降 10% 怎么分析"）
- mock interview 3 次
- 产出：业务题答案库

### 6 个月长线路线

| 阶段 | 内容 | 目标产出 |
|------|------|---------|
| 月 1-2 | SQL 高级 + Python + 1 段实习 | 可独立完成提数 |
| 月 3-4 | 统计 + 机器学习 + AB 实验 | 可独立完成分析 |
| 月 5-6 | 业务深度 + 行业研究 | 可输出战略洞察 |

### 推荐资源

- **SQL**：牛客网 SQL 题库、LeetCode 数据库题
- **Python**：《Python for Data Analysis》、Kaggle 入门
- **统计学**：《商务与经济统计》、可汗学院统计学
- **可视化**：Tableau 官方教程、B 站 Tableau 实战
- **业务**：阿里《数据分析实战》、GrowingIO 博客
