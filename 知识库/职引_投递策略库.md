## 二、投递渠道（8 大渠道 + 优先级）

### 第一梯队（必投）

#### 1. 公司官网（⭐⭐⭐⭐⭐）
- **优点**：最权威，HR 直接看
- **缺点**：流程慢，回复慢
- **投递动作**：
  - 列出 30 家目标公司
  - 进入官网 → "校园招聘" → 注册账号 → 投递
  - 每天投 5 家，1 周投完 30 家

#### 2. 牛客网（⭐⭐⭐⭐⭐）
- **优点**：校招信息最全，有讨论区
- **使用方式**：
  - 注册账号 → 进入"校招"板块
  - 订阅"2026 校招"频道
  - 用关键词搜索（如"产品经理"+"2026"）
  - 投递时同步更新"投递记录表"

#### 3. 校招公众号（⭐⭐⭐⭐）
- **推荐关注**：
  - 互联派（校招信息聚合）
  - 应届生求职网
  - 校招巴士
  - Offer 先生
- **使用方式**：每天看推送，看到合适的就投

### 第二梯队（重要）

#### 4. Boss 直聘（⭐⭐⭐⭐）
- **优点**：HR 直接聊，反馈快
- **缺点**：HR 素质参差不齐
- **使用方式**：
  - 设置"2026 应届生"标签
  - 主动打招呼（每天 30 家）
  - 准备打招呼话术（见下文）

#### 5. 实习僧（⭐⭐⭐⭐）
- **优点**：校招信息多
- **使用方式**：同上

#### 6. 智联招聘 / 前程无忧（⭐⭐⭐）
- **优点**：传统大公司多
- **缺点**：流程慢，HR 反应慢

### 第三梯队（补充）

#### 7. 脉脉 / LinkedIn（⭐⭐⭐）
- **优点**：可联系校友内推
- **使用方式**：
  - 加校友微信
  - 请校友内推（成功率最高）

#### 8. 微信群 / QQ 群（⭐⭐⭐）
- **优点**：信息实时
- **缺点**：广告多
- **推荐加入**：
  - 校招互助群（牛客网有）
  - 各大学校招群
  - 求职辅导群

## 三、简历定制（4 周冲刺版）

### 简历类型

| 类型 | 用途 | 数量 |
|------|------|------|
| **通用简历** | 海投（80% 公司） | 1 份 |
| **定制简历** | 重点公司（20% 公司） | 5-10 份 |

### 定制简历做法

**步骤 1：JD 关键词提取**
- 通读 10 个同类岗位 JD
- 提炼 5-10 个高频关键词
- 例如 PM JD 关键词：用户调研、PRD、数据分析、AB 实验

**步骤 2：简历关键词匹配**
- 把这些关键词自然嵌入到简历里
- 每个关键词出现 2-3 次
- 避免堆砌（不要"关键词：xxx, yyy, zzz"）

**步骤 3：项目经历针对性调整**
- 把最相关的项目放在最前面
- 调整项目描述，突出相关技能

**步骤 4：自我评价调整**
- 用 3-5 行写出最相关的优势
- 关键词命中

### 简历投递命名规范

```
[姓名]-[学校]-[岗位]-[2026届].pdf
示例：张三-北邮-产品经理-2026届.pdf
```

## 四、投递话术（必背）

### Boss 直聘 / 实习僧 打招呼话术

**话术 1（针对大厂）**：
```
您好，我是 2026 届 [学校] [专业] 应届毕业生，
对贵公司 [岗位] 非常感兴趣。

我的核心优势：
1. [核心优势 1，如 985 学校 + 2 段大厂实习]
2. [核心优势 2，如 side project GitHub 200 stars]
3. [核心优势 3，如 AI 工具重度用户]

希望能有机会加入贵公司，期待您的回复。
```

**话术 2（针对中小公司）**：
```
您好，我是 2026 届应届生，应聘 [岗位]。

我具备以下能力：
- [技能 1]（熟悉/精通）
- [技能 2]（熟悉/精通）
- [技能 3]（熟悉/精通）

希望能面试贵公司岗位，谢谢。
```

### 内推话术

**发给校友 / 学长学姐**：
```
[学长/学姐] 您好，我是 [学校] [专业] [年级] 的 [姓名]，
看到您在 [公司] 工作，想请教一下 [岗位] 的校招情况。

我了解到您可以内推 [岗位]，方便的话能否帮我推荐一下？
附件是我的简历：[简历链接]

非常感谢！
```

**注意事项**：
- ❌ 不要群发（学长学姐会反感）
- ❌ 不要长篇大论
- ✅ 简单介绍 + 简历附件
- ✅ 表达感谢（哪怕没被内推）

| 公司 | 岗位 | 投递渠道 | 投递日期 | 简历版本 | 笔试日期 | 一面日期 | 二面日期 | 三面日期 | Offer | 备注 |

### 投递记录表的价值

1. **避免重复投递**：跟踪每家公司的进度
2. **复盘**：失败的公司总结经验
3. **激励**：看到已投 50/100/150 家
4. **决策**：对比 offer 时一目了然

### 必追踪的指标

- **投递总数**：目标 100-200 家
- **笔试通过率**：目标 50%+
- **一面通过率**：目标 50%+
- **总 offer 数**：目标 2-3 个

## 六、笔试准备

### 笔试类型

| 公司 | 笔试形式 | 时长 |
|------|---------|------|
| 字节 | 牛客网编程 4 题 | 120 分钟 |
| 阿里 | 牛客网编程 + 选择题 | 150 分钟 |
| 腾讯 | 牛客网编程 + 行测 | 120 分钟 |
| 美团 | 牛客网编程 | 90 分钟 |
| 京东 | 赛码网编程 | 120 分钟 |

### 笔试难度分布

| 难度 | 占比 |
|------|------|
| 简单 | 30% |
| 中等 | 50% |
| 困难 | 20% |

### 笔试准备清单

| 时间 | 内容 |
|------|------|
| 前 1 月 | LeetCode 热题 100（每日 2 题） |
| 前 2 周 | 模拟笔试（牛客网 / 赛码网） |
| 前 3 天 | 复习错题本 |
| 前 1 天 | 准备模板代码（import、main、TreeNode 等） |

### 笔试通用技巧

1. **先做简单的**：每题分配 30 分钟
2. **先暴力再优化**：先 AC，再考虑时间复杂度
3. **准备模板**：链表、二叉树、图、排序代码
4. **检查边界**：数组越界、空指针、空字符串
5. **心态稳定**：1 题做不出不影响后面

## 七、面试跟进（关键中的关键）

### HR 面试后必问的 3 个问题

```
1. "请问这个岗位的招聘流程大概需要多久？"
2. "如果有幸通过面试，结果大概什么时候通知？"
3. "如果方便的话，可以加您微信吗？方便后续沟通。"
```

### 面试后跟进邮件（24 小时内）

**邮件模板**：
```
[HR 姓名] 您好：

非常感谢您和团队今天给我面试的机会。
我对 [岗位] 非常感兴趣，[1-2 句话表达对岗位/团队的兴趣]。

[1-2 句话总结自己最匹配岗位的核心优势]

期待您的进一步反馈，祝工作顺利！

[姓名]
[学校] [专业] [年级]
[电话]
```

### 没回复怎么办（72 小时）

1. **第 1 次**：发邮件问进度（礼貌）
2. **第 3 天**：再次跟进（如果 1 次没回）
3. **第 7 天**：直接问"是否还在流程中"
4. **第 14 天**：放弃，转投其他

### 跟进话术（电话 / 微信）

```
[HR 姓名] 您好，我是 [姓名]，
[时间] 面试了贵公司 [岗位]，
想问一下现在面试结果出来了吗？

如果有需要补充的信息，我可以提供。

谢谢您，期待您的回复。
```

## 八、Offer 抉择（最容易后悔的环节）

### Offer 对比维度（10 个）

| 维度 | 权重 |
|------|------|
| **薪资** | 25% |
| **公司平台** | 20% |
| **岗位匹配度** | 15% |
| **发展空间** | 15% |
| **工作地点** | 10% |
| **加班强度** | 5% |
| **团队氛围** | 5% |
| **业务前景** | 5% |

### 评分卡（示例）

| 维度 | Offer A（字节） | Offer B（美团） |
|------|--------------|--------------|
| 薪资 | 9 | 8 |
| 平台 | 10 | 9 |
| 岗位匹配 | 8 | 9 |
| 发展空间 | 9 | 8 |
| 工作地点 | 8 | 9 |
| 加班 | 5 | 7 |
| 团队 | 8 | 8 |
| 业务 | 9 | 8 |
| **总分** | **8.25** | **8.25** |

### 抉择原则

1. **不要只看薪资**：差 5w 选差的公司不划算
2. **不要只看平台**：差的公司也能学东西
3. **看直属 leader**：跟对人比进对公司重要
4. **看团队氛围**：决定你未来 2-3 年的幸福度
5. **看业务前景**：夕阳行业 vs 朝阳行业

## 九、薪资谈判（关键技巧）

### 谈薪原则

1. **永远不要先报价**：让 HR 先出价
2. **知道市场价**：用 offershow、看准网、脉脉查
3. **多个 offer 是筹码**：至少 2 个 offer 再谈
4. **委婉不撒谎**：不要说谎，但可以不说全部

### 谈薪话术

**HR：你的期望薪资是多少？**

```
谢谢您的提问。

我了解到贵公司该岗位的薪资范围是 [范围]，
我对这个范围比较满意。

不过我手上还有其他公司的 offer，
整体薪资在 [略高范围]。

如果贵公司能在 [目标薪资] 范围内，
我非常愿意加入贵公司。

谢谢您的考虑。
```

### 薪资包组成

| 部分 | 说明 |
|------|------|
| **Base** | 基本工资（月薪 × 12） |
| **Bonus** | 年终奖（通常 0-6 个月） |
| **股票** | 限制性股票 / 期权 |
| **签字费** | 部分公司有 |
| **补贴** | 餐补 / 房补 / 交通补 |

### 询问话术

```
请问贵公司的薪资包是怎样的？
- 月薪多少？年终奖几个月？
- 是否有股票？分几年归属？
- 是否有签字费？
- 餐补 / 房补 / 交通补 等福利？
```

## 十一、4 周冲刺成功率统计

| 起点 | 目标 | 4 周冲刺成功率 |
|------|------|--------------|
| 985 + 2 段大厂 | 大厂 SSP | 80%+ |
| 985 + 1 段大厂 | 大厂 SP | 60%+ |
| 211 + 1 段大厂 | 大厂 SP | 40%+ |
| 211 + 0 实习 | 大厂 offer | 10-20% |
| 双非 + 1 段中厂 | 中厂 offer | 50%+ |
| 双非 + 0 实习 | 中厂 offer | 20-30% |
| 双非 + 0 实习 | 大厂 offer | < 5% |

**结论**：4 周冲刺能让你拿到"匹配你背景的 offer"，但**无法跨越式升级**——985 拿到大厂 SSP 是正常的，双非拿到大厂 offer 是奇迹。
