## 📖 项目简介

「**职引 · AI职业诊断官**」是一款面向大学生的 AI 就业竞争力诊断智能体，构建于**科大讯飞星辰 Agent 平台**。通过多轮启发式、人设化的结构化对话，深挖求职者教育背景、实习经历与技能画像，联动**实时在线 JD 联网检索**与**多维专业求职知识库 (Dual-RAG)**，精准诊断能力长短板，并生成结构化诊断报告、Unicode 可视化进度条与 4 周定制冲刺计划。

## 🛠 快速复现与部署

1. 登录 [科大讯飞星辰 Agent 平台](https://agent.xfyun.cn)。
2. 创建工作流应用，导入对应版本的 `.yml` 文件（如初赛版 `职引 · AI职业诊断官.yml` 或复赛优化版）。
3. 如需启用知识库检索，在平台上传 `知识库/` 目录中的 markdown 文档并关联节点。
4. 调试并发布至讯飞星火 Web 端 / 移动端即可体验。
