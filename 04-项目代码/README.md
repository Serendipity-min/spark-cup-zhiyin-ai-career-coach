# 职引 · AI职业诊断官 —— 04-项目代码交付说明

## 一、交付包概览与项目事实口径

　　本目录 `04-项目代码` 为「职引 · AI职业诊断官」全国大学生职业竞争力诊断智能体的**最小可复现交付包**。本项目属于低代码/大模型工作流应用，交付包涵盖最终 Workflow YML 配置、10 篇专业 RAG 知识库、自动化 API 回归测试 Python 工程、架构与复现文档及完整性哈希校验清单。

> [!NOTE]
> **真实基线统计口径**：
> - **工作流节点数**：**22 个节点**
> - **工作流连线数**：**28 条连线**
> - **交互问答轮次**：正常路径为 **3 轮核心问答中断**（Q1 目标岗位识别 → Q2 学习背景与年级 → Q3 技能证书与项目实践）
> - **核心能力链条**：输入意图预识别 → 状态机断点路由与会话重置 → 联网实时 JD 检索 → RAG 知识库检索 → 多源证据融合生成 → Python 轻量质量门禁

## 三、环境与依赖

- **Agent 运行平台**：科大讯飞星辰 Agent 平台（开通 Spark 大模型与联网搜索插件权限）
- **Python 回归测试依赖**：
  - `Python >= 3.10`
  - `requests >= 2.31.0`
  - `python-dotenv >= 1.0.0`
  - `pyyaml >= 6.0.1`

## 四、极简复现步骤

```text
1. 登录星辰 Agent 平台 (https://agent.xfyun.cn) 并创建工作流。
2. 导入 workflow/职引_AI职业诊断官_Final.yml。
3. 在当前账号创建知识库，上传 knowledge_base/ 下的 10 篇 Markdown 文档。
4. 重新绑定联网搜索插件与知识库资源。
5. 检查大模型授权，在线保存并调试。
6. 发布工作流；如需进行自动化回归测试，发布为 API 并获取 flow_id 与凭据。
7. 在 api_regression/ 中按 README.md 配置 .env 后执行 python -m src.runner 进行全量回归。
```

## 五、异常处理与耗时基准说明

1. **联网检索与 RAG 兜底**：当外部招聘平台 JD 检索无匹配结果或知识库未覆盖冷门岗位时，工作流自动启用超时降级与通用常识库兜底，绝不产生流程异常或虚构事实。
2. **生成耗时说明**：前 3 轮交互响应通常在 2~3 秒内完成；最后一次证据融合与完整诊断报告生成耗时相对较长（API 回归实测平均生成耗时约 **91.83 秒**），属大模型高质量长文本生成的正常表现。
