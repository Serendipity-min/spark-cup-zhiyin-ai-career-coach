# 校招评分标准库 · 2026 版

## 综合评级标准（S/A/B/C）

### S 级（≥8.5/10，985 + 大厂实习 + 项目 + 论文）
- **学校**：985 或强势 211（北邮/西电/南航等）
- **实习**：2 段及以上大厂核心岗实习
- **项目**：有完整上线的个人项目（含 GitHub/小程序/App）
- **竞赛/论文**：至少 1 项（数学建模国赛/互联网+/ACM 区域赛/顶会论文）
- **技能**：岗位核心技能精通 + 1 项特长

### A 级（7.0-8.4/10，211 + 1 段大厂实习）
- **学校**：211 或双非强校
- **实习**：1 段大厂或独角兽实习
- **项目**：课程项目 + 1 个个人 side project
- **竞赛/论文**：可有可无
- **技能**：岗位核心技能熟练

### B 级（5.5-6.9/10，本科 + 普通实习或无实习）
- **学校**：普通本科
- **实习**：1 段中小公司实习或无实习
- **项目**：课程项目为主
- **技能**：基础技能达标
- **现状**：占应届生 50%+，是 4 周冲刺的最大群体

### C 级（≤5.4/10，本科 + 0 实习）
- **学校**：普通本科
- **实习**：无
- **项目**：课程作业
- **技能**：基础薄弱
- **建议**：先补基础再投简历

## 4 周冲刺标准（针对 B 级 → A 级）

### 第 1 周：基础 + 简历
- 投递目标：30 家公司 JD 通读
- 简历：1 份定制简历 + 1 份通用简历
- 输出：投递记录表 + JD 关键词分析

### 第 2 周：项目 + 技能
- 项目：1 个深度 side project（含 GitHub README）
- 技能：岗位核心技能 1 项达到熟练
- 输出：项目文档 + 技能 demo

### 第 3 周：笔面试准备
- 笔试：刷 100 道岗位真题
- 面试：mock interview 3 次
- 输出：错题本 + 面试录音

### 第 4 周：投递 + 复盘
- 投递：每天 10 家公司
- 复盘：每场面试录音回放
- 输出：投递跟踪表 + offer/拒信分析

## 评级影响因素权重（满分 100）

| 因素      | 权重 | S 级              | A 级      | B 级     |
| --------- | ---- | ----------------- | --------- | -------- |
| 学校      | 25%  | 985               | 211       | 普通本科 |
| 实习      | 35%  | 2 段大厂          | 1 段大厂  | 中小公司 |
| 项目      | 25%  | 完整 side project | 课程项目+ | 课程作业 |
| 竞赛/论文 | 10%  | 国赛/顶会         | 校赛      | 无       |
| 技能      | 5%   | 精通+特长         | 熟练      | 达标     |
