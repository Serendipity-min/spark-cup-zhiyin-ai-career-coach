## 知识库检索接入规范

1. **知识库格式**：纯文本 Markdown 结构化文档，支持分段与分级标题切片。
2. **平台切片配置**：建议分块大小（Chunk Size）设置为 500~800 字符，重叠度（Overlap）设置为 10%~15%。
3. **工作流调用**：通过工作流节点 `knowledge-base::a8726d32-5e7c-4f18-8cbc-05e942663ed6` 关联检索，以用户目标岗位作为检索关键词，提取 Top-N 知识块注入到后续大模型 Prompt 中。
