## 一、产品经理（PM）——互联网

### 4周冲刺路线（无经验 → 1段"包装实习"）

**Week 1：JD通读 + 简历打底**
- 每日2h：通读10个PM JD，提炼高频关键词
- 每日1h：用墨刀/Figma仿造1个产品的PRD
- 产出：1份PM定制简历 + 1份PRD作品

**Week 2：项目深度复盘**
- 选1个校园/实习项目，按STAR法则写1000字深度复盘
- 学SQL基础（窗口函数、JOIN）
- 产出：项目复盘文档 + SQL 50题刷题笔记

**Week 3：产品思维训练**
- 每日1个Case Study：分析1个产品的功能设计逻辑
- 写3篇产品分析文章（每篇800字）
- 产出：产品分析作品集

**Week 4：模拟面试**
- 找3位学长/朋友mock interview
- 准备30个高频产品面试题答案
- 产出：面试录音 + 复盘笔记

**6个月长线路线（0 → 大厂offer）**
- 月1-2：基础 + 1段大厂实习
- 月3-4：进阶 + 项目深度
- 月5-6：笔面试冲刺

**推荐资源**
- 公众号：俞军产品方法论、产品犬舍、三节课、人人都是产品经理
- 网站：即刻、知乎产品话题、36氪
- 书籍：《俞军产品方法论》、《人人都是产品经理》、《启示录》
- 课程：起点学院产品经理培训、B站产品经理免费课
