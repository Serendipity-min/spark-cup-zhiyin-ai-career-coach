## 案例 1：985 本科 + 2 段大厂实习 → 字节 S 级 offer

### 个人背景
- **学校**：北京邮电大学（211 强校，计算机相关专业）
- **专业**：计算机科学与技术
- **GPA**：3.7/4.0（前 20%）
- **竞赛**：ACM 区域赛金牌、蓝桥杯国赛一等奖
- **实习**：
  - 字节跳动 · 后端开发实习生（2025.3-2025.6）
  - 阿里巴巴 · 后端开发实习生（2025.7-2025.9）
- **项目**：1 个完整 side project（仿知乎，Spring Boot + Redis + ES，GitHub 800 stars）

### 求职过程

**秋招启动（2025.8）**：
- 提前批投递 50 家公司
- 笔试通过率 90%
- 一面通过率 80%

**Offer 收割（2025.10-2025.11）**：
- 字节跳动后端开发 · S 级 offer（SSP）
- 阿里巴巴 Java 开发 · A 级 offer（SP）
- 腾讯后台开发 · A 级 offer
- 美团到店后端 · S 级 offer

**最终选择**：字节跳动（SSP，年薪 50w+）

### 4 周冲刺做了什么

**Week 1：JD 分析 + 简历**
- 通读 30 个大厂后端 JD，提炼核心能力 12 项
- 用"职引 AI 诊断"做能力评估，得到 8.5/10 分
- 写 1 份定制简历（针对字节）

**Week 2：项目深度**
- 复盘字节实习项目（写 5000 字深度文档）
- 给 side project 加 3 个新特性（Redis 限流 + ES 搜索 + Docker 部署）

**Week 3：笔面试准备**
- 刷 LeetCode 热题 100（前 60 题已掌握，重点刷剩余 40 题）
- 整理 50 道计算机基础八股答案
- 找同学 mock 3 次

**Week 4：实战 + 复盘**
- 投递 30 家公司
- 7 场面试，全部通过
- 复盘每场面试录音

### 成功经验
1. **早投递**：提前批 8 月就开始，比同学早 1 个月
2. **多面试**：从面试中学习，面试越多越好
3. **深项目**：side project 真的有 800 stars，面试加分
4. **常复盘**：每场面试都录音回放

### 失败教训
- 第一次面试（阿里）因为紧张，算法题没做出来 → 后来专门练白板
- 美团二面问分布式，自己答得不好 → 后来专门补分布式

## 案例 3：双非本科 + 0 实习 → 通过 4 周冲刺拿下 1 个 offer

### 个人背景
- **学校**：山东某双非一本
- **专业**：信息管理与信息系统
- **GPA**：3.2/4.0（前 40%）
- **竞赛**：互联网+省赛铜奖
- **实习**：无
- **项目**：课程项目 2 个 + 1 个 side project（校园二手交易小程序）

### 求职过程

**秋招启动（2025.10，比别人晚 1 个月）**：
- 用"职引 AI 诊断"评估，得到 4.5/10（C+ 级）
- 诊断建议："4 周冲刺 C → B+，需要补项目 + 投中小公司"

**4 周冲刺**：
- Week 1：JD 分析 + 简历重写
- Week 2：side project 升级（从 0 到 GitHub 100 stars）
- Week 3：八股准备 + 算法 100 题
- Week 4：投递 100 家公司（海投）

**Offer 收割（2025.11-2025.12）**：
- 某二线互联网公司 · 后端开发 · B 级 offer（年薪 18w）
- 某创业公司 · 全栈开发 · B+ 级 offer（年薪 22w）
- 某外包公司 · Java 开发 · B 级 offer（年薪 15w）

**最终选择**：某二线互联网公司（B 级 offer）

### 成功经验
1. **接受现实**：先就业，再择业
2. **海投策略**：100 家公司总会有几个面试
3. **包装项目**：课程项目也能包装出深度

### 失败教训
- 大厂笔试都挂了（基础太差）
- 很多公司 HR 直接说"我们不要双非"
- 面试紧张，多次表达不清

## 案例分析：成功要素 TOP 5

1. **学校**：985 > 强 211 > 普通 211 > 双非一本 > 双非二本
2. **实习**：2 段大厂 > 1 段大厂 > 1 段中厂 > 1 段小厂 > 0 实习
3. **项目**：完整 side project（有用户） > 课程项目 + side > 课程项目
4. **竞赛/论文**：顶会论文 > 国赛一等奖 > 省赛一等奖 > 校赛
5. **执行力**：4 周冲刺 > 2 个月准备 > 海投

## 案例分析：失败教训 TOP 5

1. **启动太晚**：10 月才投，错过提前批
2. **基础不扎实**：算法题做不出来
3. **项目没深度**：被面试官追问细节就答不上来
4. **不 mock**：面试紧张，表达不清
5. **不接受现实**：死磕大厂，结果 0 offer
