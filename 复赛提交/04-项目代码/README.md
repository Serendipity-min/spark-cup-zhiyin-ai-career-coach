# 职引 · AI职业诊断官 — 项目代码说明

## 项目简介

「职引」是面向中国大学生的 AI 就业竞争力诊断智能体，基于科大讯飞星辰 Agent 平台构建。通过多轮结构化对话深挖用户能力画像，结合知识库检索与联网搜索，对比目标岗位需求生成差距分析与 4 周学习计划。

## 技术架构

- **平台**: 科大讯飞星辰 Agent 平台（工作流应用）
- **大模型**: DeepSeek-V3 / DeepSeek-V3.1
- **知识增强**: RAG 知识库检索 + 联网实时 JD 搜索
- **后处理**: Python 代码节点（验证行过滤 + 质量校验）

## 目录结构

```
04-项目代码/
├── workflow/          # 工作流配置文件 (.yml)
├── 知识库/            # RAG 知识库文档 (.md)
├── scripts/           # 辅助脚本
└── README.md          # 本文件
```

## 部署与复现指南

### 环境要求
- 科大讯飞星辰 Agent 平台账号（已实名认证）
- 讯飞 MaaS API 访问权限

### 部署步骤

1. **登录平台**: 访问 [星辰 Agent 平台](https://agent.xfyun.cn)
2. **导入工作流**: 创建工作流应用 → 导入 `workflow/` 目录下的 `.yml` 配置文件
3. **上传知识库**: 创建知识库 → 上传 `知识库/` 目录下的全部 `.md` 文件
4. **关联知识库**: 在工作流编辑器中将知识库节点关联到已创建的知识库
5. **配置基本信息**:
   - 分类: 职场
   - 开启开场白、语音转文字、下一步建议
6. **测试验证**: 使用以下测试用例验证功能
   - 输入: "我的目标是产品经理，请帮我诊断"
   - 预期: 依次询问教育背景、实践经验，最终生成 Markdown 格式诊断报告
7. **发布上线**: 发布至讯飞星火 APP / 网页端

### 测试用例

| 序号 | 目标岗位 | 用户背景 | 预期评级 |
|------|----------|----------|----------|
| 1 | 后端开发 | 大三工科，有小公司实习 | B+ |
| 2 | 数据分析师 | 有 Hive/SQL 实习经验 | B+ |
| 3 | 产品经理 | 应届生，岗位未定 | B |

## 依赖说明

- 工作流配置基于星辰 Agent 平台 DSL v1 规范
- 知识库文件为纯 Markdown 格式，无额外依赖
- Python 代码节点使用标准库 `re`，无需安装第三方包
